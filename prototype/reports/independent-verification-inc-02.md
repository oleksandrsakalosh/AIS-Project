## Reproduction for SC-A10

1. From `prototype/`, run `& ./.venv/Scripts/python.exe -m app.seed --db <temporary-db>` and `& ./.venv/Scripts/python.exe -m app.bootstrap_admin --db <temporary-db>`. Use a fictional administrator account.
2. Set `$env:POC_DB_PATH` to that database path and start Uvicorn on loopback as shown above. Open the reported address in Chrome and set the responsive viewport to 320 × 844 CSS pixels.
3. Sign in as the administrator. The app opens `/staff`. The same result occurs with an active receptionist provisioned through **Účty**.
4. Evaluate `[document.documentElement.clientWidth, document.documentElement.scrollWidth, document.querySelector("h1").clientWidth, document.querySelector("h1").scrollWidth]` in the browser console. The result was `[320, 324, 226, 277]`. The word **Zamestnanecký** exceeds its heading box, making the document scroll horizontally by 4 CSS pixels.

Expected under SC-A10 and the responsive browser baseline, the heading and staff page fit within the 320-pixel viewport. At 360 and 390 pixels the receptionist document fit within the viewport. The heading still extended past its own content box at 360 pixels.
